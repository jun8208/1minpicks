# 바다 밑의 독도 — 독도 해산 3D 영상

물 위로 보이는 독도(187,554 m²)가 사실은 거대한 해저 화산체(독도 해산)의 꼭대기라는 점을,
실제 수심 자료로 만든 3D 모형으로 보여 주는 54초짜리 영상입니다.

| 파일 | 규격 | 용도 |
| --- | --- | --- |
| `out/dokdo_seamount_16x9.mp4` | 1920×1080, 30 fps, 54초, 무음 | 일반 가로 영상 |
| `out/dokdo_seamount_9x16.mp4` | 1080×1920, 30 fps, 54초, 무음 | 쇼츠·릴스용 세로 영상 |

## 영상 구성

| 시간 | 장면 | 화면에 나오는 내용 |
| --- | --- | --- |
| 0–5초 | 수면 위의 독도 (실제 비율) | 물 위 넓이 187,554 m², 최고점 168.5 m |
| 6–11초 | 하늘로 물러나며 내려다보기 | 넓은 동해 위의 작은 점, 축구장 약 26개 넓이 |
| 12–19초 | 바닷물 걷어 내기 | 독도 해산·심흥택 해산·이사부 해산이 드러남 |
| 20–28초 | 높이 비교 | 해저에서 꼭대기까지 약 2,170 m — 한라산(1,947 m), 롯데월드타워(555 m)와 나란히 |
| 30–40초 | 위에서 본 넓이 비교 | 밑면 약 560 km²에 서울특별시 경계(605 km²)를 겹쳐 놓음, 물 위 독도는 그 약 3,000분의 1 |
| 42–48초 | 과장 없는 실제 비율 | 폭 약 27 km × 높이 약 2.2 km, 부피의 99.99% 이상이 물속 |
| 49–54초 | 마무리 | "우리가 보는 독도는 거대한 해산의 꼭대기입니다." |

12–33초 구간은 산의 모양이 잘 보이도록 **높이를 3배 과장**했고, 화면에 그 사실을 계속 표시합니다.
첫 장면과 42초 이후는 과장 없는 실제 비율입니다. 높이끼리의 비교(한라산·롯데월드타워)는
모두 같은 배율이 적용되므로 과장과 상관없이 정확합니다.

## 수치의 근거

화면에 나오는 해산의 크기는 인용한 값이 아니라 **수심 격자에서 직접 잰 값**입니다
(`tools/build_data.py`, 결과는 `data/scene.json` 의 `facts`).

| 항목 | 값 | 재는 방법 |
| --- | --- | --- |
| 밑면 수심 | 약 2,000 m | 다른 해산과 붙지 않은 서쪽 사면의 평균 단면에서 경사가 3° 아래로 눕는 지점이 중심에서 14 km, 수심 1,993 m |
| 전체 높이 | 약 2,170 m | 2,000 m + 서도 최고점 168.5 m |
| 밑면 넓이 | 약 560 km² (559.8) | 수심 2,000 m 등심선 안쪽 가운데 독도 해산에 속하는 부분 |
| 밑지름 | 약 27 km (26.7) | 밑면과 넓이가 같은 원의 지름. 실제 밑면은 동서 28 km × 남북 36 km 의 찌그러진 모양 |
| 부피 | 약 510 km³ | 수심 2,000 m 위쪽 |
| 물 위 부피의 비율 | 0.01% 미만 | 물 위 부피를 "넓이 × 최고 높이"로 크게 잡아도 0.006% |
| 물 위 넓이 대비 | 약 3,000배 (2,985) | 559.8 km² ÷ 0.187554 km² |

독도 해산은 동쪽으로 심흥택 해산과 수심 약 470 m 의 안부로 이어져 있어 어디까지가 독도 해산인지
경계가 뚜렷하지 않습니다. 여기서는 봉우리에서부터 물을 채워 내려가는 방식(유역 분할)으로
해산들을 나눴습니다. 경계를 다르게 잡으면 넓이와 부피는 10% 안팎 달라질 수 있습니다.
공개 자료의 "수심 약 2,000 m 해저에서 솟은, 지름 25~30 km 의 평정해산"이라는 설명과 같은 범위입니다.

비교 대상: 독도 총면적 187,554 m², 서도 168.5 m·동도 98.6 m (외교부·경상북도 공표값),
서울특별시 605.2 km², 한라산 1,947 m, 롯데월드타워 555 m, 축구장 105 m × 68 m.

## 알아 둘 점

- **수심 자료의 한계** — GMRT 는 정밀 측량 구간과 보간한 구간이 섞인 합성 격자입니다. 독도 해산의
  사면은 정밀 측량 구간이지만 일부는 해상도가 낮고, 이웃 해산의 정상 수심은 국립해양조사원 공표값
  (심흥택 146 m, 이사부 136 m)과 차이가 납니다. 영상에서는 이웃 해산의 수치를 쓰지 않았습니다.
- **섬의 모양** — 해안선은 OpenStreetMap 의 실제 윤곽이지만, 섬의 높낮이는 정밀 지형 자료가 아니라
  공식 최고점(서도 168.5 m, 동도 98.6 m)에 맞춰 만든 근사 모형입니다.
- **서울 경계** — 크기 비교를 위해 해산 밑면 중심에 같은 축척으로 겹쳐 놓은 것입니다.
- 영상에 소리는 없습니다.

## 다시 만들기

```bash
npm install                       # three.js, Pretendard 글꼴
npm run render                    # 가로 영상  → out/dokdo_seamount_16x9.mp4
npm run render -- --aspect 9x16   # 세로 영상  → out/dokdo_seamount_9x16.mp4
npm run serve                     # http://127.0.0.1:8080 에서 실시간 미리보기 (스페이스: 멈춤, ←/→: 1초 이동)
```

렌더링에는 Node.js, Playwright(Chromium), ffmpeg 가 필요합니다. GPU 없이 소프트웨어 렌더링으로
영상 하나에 15분쯤 걸립니다. `--stills 3,24,34` 처럼 주면 그 시각의 정지 화면만 PNG 로 뽑습니다.

원본 자료부터 다시 만들려면 (`pip install numpy scipy pillow contourpy` 필요):

```bash
bash tools/fetch_raw.sh           # 수심 격자와 외곽선을 raw/ 에 내려받기
npm run data                      # raw/ → data/ (격자 가공 + 계측)
```

| 경로 | 내용 |
| --- | --- |
| `web/main.js` | 장면 조립, 카메라 동선, 자막 — 시간 t 를 주면 그 순간을 그리는 구조 |
| `web/shaders.js` | 지형·바다·섬 셰이더 |
| `tools/build_data.py` | 수심 격자 가공, 해산 계측, 섬 모형 생성 |
| `tools/render.mjs` | 프레임 단위 캡처 후 ffmpeg 로 인코딩 |
| `data/` | 가공된 장면 데이터 (지형 2072×1214 격자, 섬 모형, 외곽선, 계측값) |

자막 문구와 시간은 `web/main.js` 의 `cap(...)`·`tag(...)` 호출에서, 카메라 동선은 `KEYS_L`(가로)·
`KEYS_P`(세로)에서 바꿀 수 있습니다.
